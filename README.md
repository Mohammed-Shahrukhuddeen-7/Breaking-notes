# Breaking Notes

Breaking Notes is a study workspace for keeping study sessions, course notes, deadlines, and progress together.

## Current features

- **Study timer** — Pomodoro sessions with points and streak tracking.
- **Notes Vault** — Browse and download course notes by semester and subject. Admins can manage the library and upload notes.
- **Deadline Tracker** — Create and track study tasks.
- **Leaderboard** — Compare study points and streaks.
- **Profile** — View your study progress and account details.
- **Admin tools** — Manage Notes Vault content and other administrative features.
- **Light and dark themes** — Switch between the two appearances from the navigation area.
